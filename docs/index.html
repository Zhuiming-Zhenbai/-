功能特性

🖱️

划词翻译

选中任意文字，按下快捷键（默认 Alt+Q），鼠标旁立刻弹出翻译。

🔍

屏幕识别翻译

图片、PDF、游戏里无法选中的文字？用透明识别框框住，一键识别并翻译。

📡

离线翻译

内置离线引擎（英文 / 日文 → 中文），没网也能翻译。

🔌

自定义 API

支持 DeepSeek、OpenAI、Kimi、通义千问等多家服务商，可自由配置。

💬

原文 / 译文切换

一键切换显示原文或译文，并支持复制译文。

⚙️

自由可调

引擎开关、快捷键、边框颜色、模型资源、多套 API 配置都能按需设置。

使用说明

  1. 下载并安装（或运行便携版）。
  2. 首次使用：点托盘图标 → 设置，填好 API Key（或切换到「离线翻译」）。
  3. 划词翻译：选中文字 → 按 Alt+Q。
  4. 屏幕识别：按 Alt+W 打开识别框，框住文字 → 点「翻译」。
  5. 离线翻译 / 屏幕识别首次使用会自动下载模型，请联网等待一次。
