# 发布流程说明

本文档说明如何打包、发布「小白翻译」并让用户更新。

## 一、打包

前置：已安装依赖（`npm install`）。国内网络建议先设置镜像。

```bash
# 一次性打包（生成安装版 + 便携版）
export ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npm run dist
```

产物在 `dist/`：

| 文件 | 说明 |
|------|------|
| `小白翻译-Setup-0.1.0.exe` | NSIS 安装包（推荐给用户，带桌面/开始菜单快捷方式） |
| `小白翻译-Portable-0.1.0.exe` | 便携版（免安装，双击即用） |
| `win-unpacked/` | 解包后的应用（调试用，可不发） |

> 说明：安装包约 170MB，主要来自离线翻译引擎（onnxruntime + transformers）与 OCR 内核。后续可把离线模型/引擎改成「按需下载」进一步缩小体积。

## 二、更新版本号

打包前修改 `package.json` 的 `version`（如 `0.1.0` → `0.2.0`），产物文件名会自动带新版本号。

## 三、发布（上传安装包）

选一个或多个渠道上传 `小白翻译-Setup-0.2.0.exe`：

- 蓝奏云 / 网盘（国内用户下载体验好）
- GitHub Release / Gitee Release（可生成直链，配合自动更新）
- 阿里云 OSS / 腾讯云 COS（直链稳定）

## 四、配置自动更新

1. 把安装包上传到**可直链下载**的地址，得到下载 URL。
2. 修改 `release/latest.json`：
   ```json
   {
     "version": "0.2.0",
     "url": "https://你的下载地址/小白翻译-Setup-0.2.0.exe",
     "notes": "本次更新说明"
   }
   ```
3. 把 `latest.json` 也上传到一个**可直链访问**的地址（如 `https://xxx/latest.json`）。
4. 软件「设置 → 软件设置 → 软件更新」里，把「更新地址」填成 `latest.json` 所在目录（如 `https://xxx`），保存。
5. 用户点「检查更新」时：发现新版本 → 提示 → 浏览器打开下载页。

> 国内可直链的推荐：Gitee 仓库 raw 链接、阿里云 OSS、腾讯云 COS。GitHub 的 raw 链接在国内常被墙。

## 五、注意事项

- **未签名警告**：未买代码签名证书的 exe，用户首次运行会看到 SmartScreen「已保护你的电脑」，点「更多信息 → 仍要运行」即可。要消除需购买代码签名证书。
- **离线模型**：模型不在安装包内，用户首次使用离线翻译/识别时会自动下载（约数百 MB），请留意网络说明。
- **体积**：当前安装包约 170MB（含离线引擎与 OCR 内核），属正常。
