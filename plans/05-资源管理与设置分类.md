# 计划：资源管理 + 设置窗口分类 + 识别窗口外观

## Context

三项改进：

1. **资源管理**：离线模型 / 识别语言数据首次使用时自动下载，用户看不到「资源是什么」。新增资源管理页：查看、解释用途、百分比进度下载、删除，支持「全部下载 / 全部删除」。
2. **设置分类**：设置窗口改为左侧导航 + 右侧内容（快捷键设置 / 翻译引擎设置 / 资源管理 / 软件设置）。
3. **识别窗口外观**：用户可自定义颜色；默认只保留上边框（工具条），点击窗口时才显示完整边框范围（便于调整大小）。

现状（已读代码）：
- 模型缓存：`userData/models/Xenova/opus-mt-en-zh`、`.../opus-mt-ja-en`（FileCache 按请求路径存放）。
- 语言数据：`userData/tessdata/<lang>.traineddata`（eng / chi_sim / jpn）。
- 设置窗为单列长表单（settings.html/js/css），已有 provider、双快捷键、关闭行为逻辑可复用。
- 识别窗 `src/renderer/ocr/*`：目前是固定蓝色四边边框 + 常显四角手柄。

## Approach

### 1. 设置窗口左侧导航分类

- settings.html 改两栏：左 `aside` 导航（4 项）+ 右 `content-area`（4 个 `section`，点导航切换 `.active`）。
- 分类：快捷键设置（两个快捷键）、翻译引擎设置（在线 API + 离线）、资源管理、软件设置（关闭行为 + 识别窗口边框颜色）。
- 底部保留「保存 / 取消」横条；资源页下载/删除为即时操作。
- 窗口放大（约 760×620，min 640×540）。

### 2. 资源管理（新 `src/resources.js`）

- 资源清单（含用途说明）：
  | id | 名称 | 用途说明 | 定位 |
  |---|---|---|---|
  | model-en-zh | 离线翻译模型（英→中） | 离线翻译英文时使用 | models/Xenova/opus-mt-en-zh |
  | model-ja-en | 离线翻译模型（日→英） | 离线翻译日文时作为中间步骤使用（日→英→中） | models/Xenova/opus-mt-ja-en |
  | ocr-eng | 识别语言数据（英文） | 屏幕识别英文文字时使用 | tessdata/eng.traineddata |
  | ocr-jpn | 识别语言数据（日文） | 屏幕识别日文文字时使用 | tessdata/jpn.traineddata |
  | ocr-chi_sim | 识别语言数据（中文） | 屏幕识别中文文字时使用 | tessdata/chi_sim.traineddata |
- 提供 `list(userDataDir)`（cached/大小/用途）、`download(id, onProgress)`、`remove(id)`、`totalSize(userDataDir)`、`downloadAll`、`removeAll`。
- 下载复用：模型 `offline.js` 增 `downloadModel(modelId, {progress_callback})`（pipeline 触发下载并传进度）；语言数据 `ocr.js` 增 `downloadTraineddata(lang, {onProgress})`（建 worker 触发下载，logger 进度映射，无精确进度则显示不确定进度）。
- 删除：模型删目录、语言数据删单文件；删除前 `dialog.showMessageBox` 二次确认。

### 3. IPC 与资源页 UI

- preload：`getResources()` / `downloadResource(id)` / `deleteResource(id)` / `downloadAllResources()` / `deleteAllResources()` / `onResourceProgress(cb)`。
- main：对应 IPC；下载期间经 `settingsWindow.webContents.send('resource-progress', {id, progress, status})` 推送。
- 资源页：每项显示名称 + 用途说明 + 状态/大小 + 「下载/删除」按钮；下载中显示**百分比进度条**；顶部显示总占用 + 「全部下载 / 全部删除」。

### 4. 识别窗口外观

- config 增 `ocrBorderColor: '#1f6feb'`；软件设置 tab 提供颜色选择器（`<input type="color">`），get/save-settings 带该字段。
- 识别窗 renderer 加载时经 `get-ocr-config`（{ lang, borderColor }）取颜色，`setProperty('--border-color', ...)` 应用。
- CSS：
  - 默认：仅顶栏（工具条）可见，颜色用自定义色；左右/下边框与四角手柄隐藏（透明，用户可透过窗口定位）。
  - `window` `focus` 时给 `.frame` 加 `.focused`：显示左右/下边框 + 四角手柄（颜色同自定义色），便于看清范围并缩放；`blur` 时移除。
  - 截图范围仍用 `getBounds()`，与边框是否显示无关。
