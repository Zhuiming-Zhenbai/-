# 计划：反馈按钮、启动弹设置、屏幕识别入口、导航排序

## Context

四项改进：

1. 软件设置新增「用户反馈」按钮 → 点击跳转哔哩哔哩个人主页（https://space.bilibili.com/494460268），按钮上方放说明文案（引导用户发私信）。
2. 每次启动软件（首次启动、或彻底退出后台后再次启动）自动弹出设置窗口。
3. 软件设置新增「打开屏幕识别窗口」按钮，点击直接打开识别框。
4. 左侧导航把「翻译引擎设置」放到最上面，并默认选中它。

现状（已读代码）：
- `src/main.js`：`app.whenReady()` 只建托盘+弹窗，不弹设置；`second-instance` 时弹设置。
- `src/preload.js` 已有 `confirmOpenSite`（带确认弹窗），无「直接打开外链」与「打开识别窗」。
- `src/renderer/settings.html` 导航顺序：快捷键设置 / 翻译引擎设置 / 资源管理 / 软件设置，默认 active 为 shortcuts。

## Approach

1. **反馈按钮**：软件设置 tab 顶部加说明文案 + 「用户反馈」按钮；preload/main 增 `openExternal(url)`（校验 http(s) 后直接 `shell.openExternal`，无确认）。
2. **启动弹设置**：`app.whenReady()` 里在创建托盘/弹窗后调用 `createSettingsWindow()`。
3. **屏幕识别入口**：preload/main 增 `open-ocr-window` → `createOcrWindow()`；软件设置加按钮。
4. **导航排序**：settings.html 调整 nav 顺序为「翻译引擎设置 / 快捷键设置 / 资源管理 / 软件设置」，并把默认 active 改为 engine（tab 与 nav 同步）。
