# 计划：设计启动图标

## Context

为「小白翻译」设计正式启动图标（替换当前无辨识度的蓝色圆点）。

已确认：
- 图案：**对话气泡 + 双向箭头**（无文字，通用翻译符号）。
- 风格：**现代 App 风格**（圆角方形，符合 Windows）。
- 配色：蓝色（沿用主题色 `#1f6feb`，做浅→深的竖向渐变，更有质感）。

技术（已探查）：`sharp` 可栅格化 SVG；用纯矢量形状（气泡/箭头/渐变）不依赖字体，各尺寸稳定清晰。

## Approach

- 用 SVG 设计：圆角方形背景（竖向渐变蓝）+ 白色「两个对话气泡 + 中间双向箭头」。
- 气泡：左侧描边气泡（带小尾巴）、右侧实心气泡（带小尾巴），中间一个横向双向箭头（⇄），传达「翻译/双向交流」。
- 经 `sharp` 栅格化多尺寸 PNG（16/32/48/64/128/256），再打包成**多尺寸 `icon.ico`**。
- 更新 `scripts/gen-icon.js`（SVG + 多尺寸 PNG）与 `scripts/gen-ico.js`（多尺寸 ICO），重新生成 `assets/icon.png`（256）与 `assets/icon.ico`。
- 桌面快捷方式已引用 `assets/icon.ico`，重新生成后自动显示新图标。
